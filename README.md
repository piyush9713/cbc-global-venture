# CBC Global Venture

> **Sourcing India. Supplying the World.**

A production-ready single-page website for **CBC Global Venture** — a premium import-export company from Indore, India, supplying agro commodities, spices, fresh produce & essentials to buyers in 20+ countries.

## ✨ Features

- **Content Studio** — full visual CMS panel (no code needed) with Raw JSON editor
- **Product catalogue** with category filter chips and enquiry flow
- **Contact form** with modern flag-icon country dropdown, category selector & Incoterms picker
- **Global Markets** section with real flag icons (flag-icons library) for all 6 regions
- **Animated footer globe** with orbit rings, trade nodes and floating stat chips
- **Certifications** — IEC & GST prominent badges + APEDA, FSSAI, ISO, Phytosanitary
- SEO-optimised — structured data (JSON-LD), OG/Twitter cards, canonical URL
- Fully responsive — mobile-first layout

## 🚀 Deploy

### Netlify
Drop the folder into [app.netlify.com](https://app.netlify.com) — `netlify.toml` handles routing & headers automatically.

### Vercel
```bash
npx vercel
```
`vercel.json` is pre-configured with security headers and SPA fallback.

### GitHub Pages
Enable Pages on this repo → set source to `/ (root)` → access at `https://piyush9713.github.io/cbc-global-venture/index3.html`

## 🛠 Tech Stack

| Layer | Technology |
